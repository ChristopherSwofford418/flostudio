# FloStudio Visual Identity Direction — 2026-08-18

## Research synthesis

Creatify presents creative production as an accountable review-and-delivery operation: strategy, production, human quality assurance, and dashboard approval. Arcads emphasizes model choice, practical media transformations, performance-minded presets, and a shared infinite creation workflow. Pencil frames the category as an AI operating system with orchestration, governance, and a unified editor rather than a collection of isolated generators.[1][2][3]

FloStudio should not copy any competitor's interface or default to the familiar dark-violet gradient, rounded-card, left-sidebar pattern. Its differentiated position is **Portfolio Marketing OS** for owners operating many products simultaneously. The interface should make portfolio context, creative velocity, decision quality, and human control visibly central.

## Recommended direction: Signal Ledger

The redesign will use a modern editorial-operations system called **Signal Ledger**. Its visual character pairs a warm mineral paper ground with dense evergreen ink, lime signal marks, and restrained vermilion alerts. Instead of glass panels floating in a purple void, the product will resemble a living creative ledger: ruled grids, receipt-like data strips, oversized typographic moments, clipped operational stamps, and media treated as evidence.

| Element | Direction |
|---|---|
| Core palette | Ink `#11251F`, mineral `#F3F0E7`, signal lime `#C9F25D`, vermilion `#E76C48`, quiet moss `#58706A` |
| Type | Bricolage Grotesque for strategic statements; DM Mono for data, system labels, and workflow metadata |
| Layout | Asymmetric editorial canvas, visible column rules, dense but legible data rails, media framed as campaign evidence |
| Navigation | A compact operational rail with numbered system areas, active view as a printed label—not a neon pill |
| Motion | Minimal. Use fast opacity/transform states only for intent and loading feedback, not decorative effects |
| Product signature | The **Signal Index**: an at-a-glance operational measurement repeated across portfolio, campaign, review, and performance surfaces |

## Implementation priorities

1. Replace global purple/pink gradients and generic frosted cards with the Signal Ledger palette and structural grid.
2. Redesign the application shell, navigation, page headers, buttons, inputs, states, and token meter as a cohesive system.
3. Apply the system first to Portfolio, Campaign Engine, Creative Lab, Review Queue, and Performance surfaces—the routes that define the product's commercial promise.
4. Preserve existing tenancy, routing, authentication, and API behavior; this is an interface system redesign, not a data-model rewrite.
