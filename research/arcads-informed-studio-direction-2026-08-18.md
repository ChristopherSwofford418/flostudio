# FloStudio Studio Direction — Arcads-Informed, Not Copied

## Research synthesis

Arcads organizes ad production around concrete media decisions rather than an abstract AI chat experience. Its product surface begins with creator-led UGC, product image and video generation, actor formats, scripts, reusable products, presets, media transformations, and automation workflows. It uses model choice and format selection to make the creative goal legible before generation begins.[1][2]

The transferable pattern is not Arcads’ visual styling or language. It is its production logic: **choose a proven ad format, anchor it in a product asset, select the performance variables, render variations, then iterate from the generated media**. Arcads’ documentation also demonstrates the value of persistent product assets, creator/actor selection, scripts, preset workflows, transformations, and scaled variants.[3]

## FloStudio: Portfolio Ad Room

FloStudio will use an original concept called the **Portfolio Ad Room**. It will be a media-first control surface for a product portfolio, combining a visible product reference, a format-led creative brief, editable script or on-image hook, delivery placement, variant count, and a render queue.

| Arcads-inspired pattern | Original FloStudio expression |
|---|---|
| UGC, product, and actor formats | A **Format Shelf** with product showcase, founder/creator testimonial, UI walkthrough, unboxing/reveal, and before/after story lanes |
| Product upload and app placement | **Product Truth** pinned asset area sourced from the selected portfolio app or uploaded reference |
| Model choice | **Render intent** controls that describe the output goal—fast test, polished launch, or performance iteration—without exposing vendor jargon |
| Script and actor-led video | **Ad Blueprint** with hook, proof, payoff, CTA, and optional presenter direction |
| Presets and workflow automation | **Runbooks** saved per portfolio app; a runbook can create a defined set of variations from the current brand rules |
| Media editing tools | **Post-render actions** attached to every creative: revise hook, swap format, localize, crop, make static, or send to review |

## Visual direction

The Ad Room should feel like a working production desk: large media canvas, utility rail, visible format strips, dense operational metadata, and no floating AI chat cards. The audience should see real creative output and the exact choices that lead to it. The signal-lime and vermilion FloStudio system remains as a signature, but the layout becomes media dominant rather than dashboard dominant.
